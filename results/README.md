# TactileSense AI: results package

Evidence of the final experiment run on 2026-10-28, generated by `python scripts/run_experiments.py`,
`python scripts/analyze_baseline.py` and `python scripts/build_results.py`.

- Every number here is copied from the files in [metrics/](metrics) or [experiment_summary.json](experiment_summary.json).
- Every image comes from real held-out test frames or from the running app.
- Smoke-test outputs (`reports/smoke/`, `models/smoke/`) are **not** part of this package.
- Tactile images shown here are derived from Real Tactile MNIST (T. Schneider et al., arXiv:2506.06361, 2025),
  licensed CC-BY-2.0.

## Headline

**Task:** classify which 3D-printed digit (0-9) a GelSight Mini sensor touched, from **one** 64x64 tactile frame.
Data: Real Tactile MNIST. The test set is the official test split: **100 unseen physical objects**, of which
**7,798 frames** show detected contact.

| Held-out test set | CNN | HOG + SVM |
|---|---|---|
| Accuracy, single frame (chance = 0.10) | **0.174** (95% CI 0.141-0.208) | **0.171** (95% CI 0.146-0.201) |
| Macro precision / recall | 0.187 / 0.181 | 0.170 / 0.183 |
| Macro-F1 | **0.181** (95% CI 0.142-0.208) | **0.159** (95% CI 0.138-0.174) |
| Object accuracy, 8 touches averaged | 0.265 | 0.301 |
| Object accuracy, 32 touches averaged | 0.316 | 0.359 |
| Latency, 1 image, 1 CPU thread (median / p95) | 6.44 / 9.54 ms | 4.96 / 7.07 ms |

CIs come from 2,000 bootstrap resamples of the **100 test objects**, not of the correlated frames.

**What the results show:**
- **Both models clearly beat chance.** Their lower CI bounds are above 0.10.
- **Neither model is reliably better.** The CNN − SVM difference intervals contain 0:
  accuracy [−0.034, +0.041], macro-F1 [−0.011, +0.053].
- **Single frames are the bottleneck.** A touch shows only a fragment of one stroke. Averaging probabilities over
  32 touches of the same object lifts accuracy from ~0.19 to 0.32-0.36. The dataset was designed for exactly this
  multi-touch setting.

## Why is the HOG + SVM weak? (validation split only)

| Variant (6,000 training frames, same Scaler → PCA → SVM) | Train acc. | Val acc. |
|---|---|---|
| All hand-crafted features | 1.000 | 0.161 |
| HOG only | 1.000 | 0.165 |
| Contact statistics only (28-D) | 0.538 | 0.122 |
| Raw 16x16 difference pixels (control) | 0.822 | 0.113 |
| **Leaky control:** same features, random *frame-level* split | 1.000 | **0.236** |

- **It memorises, it does not generalise.** Training accuracy is 100% but validation is 16%. The features
  separate individual training frames, but that separation does not transfer to unseen objects.
- **HOG carries the signal.** Contact statistics alone and raw pixels are close to chance.
- **The split protocol matters.** Letting touches of the same object fall into both training and evaluation inflates
  accuracy from 0.161 to 0.236 (+46% relative). This project reports only the object-grouped numbers.

## Failure case analysed

![failure](images/prediction_failure_example.png)

**What happened:** true digit 6, CNN predicted **8 with 99.7% confidence**, SVM predicted 3 (17.6%).

**Why:**
- **There is no digit stroke in the frame.** The frame shows a broad, diffuse change without stroke edges, which
  the contact detector counts as 14% contact.
- **The robot measured a low gel height.** It was **4.75 mm**, below the 10th percentile of test contact frames
  (6.08 mm; median 8.71 mm). The sensor most likely pressed the rubber mat next to the digit. So the detector
  produced a false positive, and the CNN classified an image that contains no class evidence.

**The general pattern:** the CNN's top-end confidence is **not calibrated**. Its 96 test predictions with
confidence ≥ 0.9 are correct only 18.8% of the time. The SVM's calibrated probabilities never exceed 0.3: less
informative, but not misleading.

## What could not be produced
- **Physical-sensor results:** no tactile hardware was used, so all results come from the public dataset.
- **Force, slip or pose results:** the dataset provides no such labels, so none are claimed.
- **Video recording:** only the script exists ([demo/demo_script.md](demo/demo_script.md)); the video itself has
  not been recorded.
